    Details that change the flow
    
    
    “Non-real-time” still streams
    This is Dograh’s name for the separate STT, text LLM, and TTS path. It is still a live voice pipeline. STT can transcribe while forwarding raw audio; the analyzer does not need a finished transcript.
    
    
    Voice activity and a user turn are separate
    The standard animation uses the default transcription-or-VAD start strategies. Minimum-word and provisional-VAD strategies change when a turn is accepted. Local VAD can report activity without immediately starting a turn.
    
    
    Some STT services own turn boundaries
    Deepgram Flux, Dograh’s Flux language path, and Cartesia ink-2 select external turn strategies by default. Local Silero is still attached, but its VAD events do not drive the default external start strategy. The non-real-time animation shows the ordinary local-VAD configuration.
    
    
    Mute strategies and startup
    The animation begins with an established audio session and an unmuted user after the greeting. Dograh configures mute-until-first-bot-complete, function-call, and workflow callback strategies. They can suppress speaking and transcription signals; realtime wrappers also gate provider audio when muted.
    
    
    Silence is not the end of the turn
    Silero uses confidence and volume thresholds and buffered analysis windows. The configured start and stop durations are 0.2 s, rounded to analyzer windows. The default speech-timeout strategy adds a 0.6 s policy wait and, in the standard path, considers STT finalization/latency. Smart Turn is an alternative stop strategy.
    
    
    Frames are asynchronous messages
    push_frame() enqueues a frame on the next or previous processor. A broadcast creates two instances. VAD’s queued broadcast is special: it queues a downstream instance on the aggregator itself so its own turn controller sees it, then pushes another upstream. The animation separates these causal steps for readability; real branches overlap.
    
    
    Optional processors
    Non-real-time voicemail inserts the detector after STT and its LLM gate before the main LLM. The recording router sits between engine callbacks and TTS. The realtime builder accepts a detector, but run_pipeline.py currently disables voicemail in realtime mode.
    
    
    Worker and observers
    PipelineWorker initializes and supervises the chain and sends StartFrame. Pipeline source/sink wrappers are omitted from the drawing. Observers watch frame traffic without occupying slots in this processor chain. A separate realtime text LLM handles out-of-band inference.
